# 泊松过程交互式可视化

《概率论与随机过程》期中作业 —— 泊松过程基本性质、叠加性、稀释性及客服中心实际应用。

## 功能概览

| 标签页 | 内容 |
|--------|------|
| **基本性质** | 样本路径阶梯图、到达间隔指数分布拟合、无记忆性验证 |
| **叠加性** | 两个独立泊松过程叠加、三图对比、强度验证 |
| **稀释性** | Bernoulli 随机筛选、保留/丢弃事件标记、稀释后强度验证 |
| **客服中心应用** | 多线路进线模拟、骚扰电话过滤、运营指标计算 |

所有模拟结果均与理论值对比，并用绿（<5%）、黄（5-10%）、红（>10%）标注相对误差。

## 快速开始

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 运行应用
streamlit run app.py

# 3. 浏览器打开 http://localhost:8501
```

## 导出独立 HTML

1. 运行 `streamlit run app.py`
2. 浏览器打开 `http://localhost:8501`
3. 点击右上角 **⋮** → **Print** → 目标选择 **"另存为 HTML"**
4. 保存后双击 `.html` 文件即可在浏览器中打开（Plotly 图表保持完整交互）

## 依赖

- Python 3.9+
- streamlit >= 1.30.0
- numpy >= 1.24.0
- plotly >= 5.18.0
- scipy >= 1.11.0
- pandas >= 2.0.0
